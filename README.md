# Royal Spin Casino Wheel — Vue 3

A high-end casino-style spin wheel web app built with Vue 3 Composition API, HTML5 Canvas, CSS, i18n English/French, and localStorage.

## Features

- Vue 3 Composition API
- Real HTML5 Canvas wheel, not div rotation
- 14 reward segments with gradients, shadows, icons and exact landing logic
- Preselected winning segment before animation
- 5–10 full turns with easing
- Tick sound, win sound and highlighted winning segment
- Fixed metallic pointer with stop bounce
- Username and balance session saved in localStorage
- Bet validation and balance deduction before spin
- English/French i18n switch
- Responsive luxury casino UI
- GitHub Pages ready

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploy the generated `dist` folder to GitHub Pages.

- `casino_session`
